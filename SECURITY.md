# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository's **Security** tab. Do not open a public issue containing credentials, private Notion content, or an exploitable vulnerability.

If private vulnerability reporting is unavailable, contact the maintainer through [@Mufid2225](https://github.com/Mufid2225). Include a description and reproduction steps, but never include an access token or private workspace data.

## Scope

This project is an agent skill and local Python helper that use Notion's official REST API as the primary transport and the official Notion MCP server as an optional fallback. Reports about unsafe mutations, bypassing user confirmation, mishandling private workspace content, or credential exposure are relevant.
